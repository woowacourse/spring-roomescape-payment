## 예약 시키기

> **POST /admin/reservations**

> **⚠️ 관리자만 수행할 수 있습니다.**

### Request

- **헤더**

  |   이름   |  자료형   |       예시 값       |            설명             |
  |:------:|:------:|:----------------:|:-------------------------:|
  | Cookie | String | token={JwtToken} | **관리자** 로그인을 통해 얻은 JWT 토큰 |

- **본문**

  |   필드    |   자료형    |    예시 값    |       설명        |
  |:-------:|:--------:|:----------:|:---------------:|
  |  date   | DateTime | 2001-01-01 | 예약시킬 날짜 (미래 일시) |
  | timeId  |  number  |     1      |   예약시킬 시간 ID    |
  | themeId |  number  |     1      |   예약시킬 테마 ID    |
  | userId  |  number  |     1      |   예약시킬 사용자 ID   |

### Response

> **201 CREATED**

- **본문**

  |         필드          |   자료형    |                                    예시 값                                    |   설명   |
  |:-------------------:|:--------:|:--------------------------------------------------------------------------:|:------:|
  |         id          |  Number  |                                     1                                      | 예약 ID  |
  |  [user](./user.md)  | JSON Map |                            {id: 1, name: "포포"}                             |  예약자   |
  |        date         |   Date   |                                 2001-01-01                                 | 예약한 날짜 |
  |  [time](./time.md)  | JSON Map |                        {id: 1, startAt: "10:00:00"}                        | 예약한 시간 |
  | [theme](./theme.md) | JSON Map | {id: 1, name: "라라랜드", description: "라라랜드입니다.", thumbnail: "thumbnail.jpg"} | 예약한 테마 |

## 모든 사용자 조회하기

> **GET /admin/users**

> **⚠️ 관리자만 수행할 수 있습니다.**

### Request

- **헤더**

  |   이름   |  자료형   |       예시 값       |            설명             |
  |:------:|:------:|:----------------:|:-------------------------:|
  | Cookie | String | token={JwtToken} | **관리자** 로그인을 통해 얻은 JWT 토큰 |

### Response

> **200 OK**

- **본문**

  아래와 같은 사용자들로 이루어진 컬렉션을 응답합니다.

  |  필드  |  자료형   | 예시 값 |       설명       |
  |:----:|:------:|:----:|:--------------:|
  |  id  | Number |  1   |     사용자 ID     |
  | name | String | "포포" | 사용자 이름 (5자 이하) |

---
