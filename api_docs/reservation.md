## 예약하기

> **POST /reservations**

### Request

- **헤더**

  |   이름   |  자료형   |       예시 값       |            설명             |
  |:------:|:------:|:----------------:|:-------------------------:|
  | Cookie | String | token={JwtToken} | **관리자** 로그인을 통해 얻은 JWT 토큰 |

- **본문**
    
  |   필드    |  자료형   |    예시 값    |        설명        |
  |:-------:|:------:|:----------:|:----------------:|
  |  date   |  Date  | 2001-01-01 | 예약하려는 날짜 (미래 일시) |
  | timeId  | Number |     1      |   예약하려는 시간 ID    |
  | themeId | Number |     1      |   예약하려는 테마 ID    |


### Response

> **201 CREATED**

- **본문**

  |         필드          |   자료형    |                                    예시 값                                    |   설명   |
  |:-------------------:|:--------:|:--------------------------------------------------------------------------:|:------:|
  |         id          |  Number  |                                     1                                      | 예약 ID  |
  |  [user](./user.md)  | JSON Map |                            {id: 1, name: "포포"}                             |  예약자   |
  |        date         |   Date   |                                 2001-01-01                                 | 예약한 날짜 |
  |  [time](./time.md)  | JSON Map |                        {id: 1, startAt: "10:00:00"}                        | 예약한 시간 |
  | [theme](./theme.md) | JSON Map | {id: 1, name: "라라랜드", description: "라라랜드입니다.", thumbnail: "thumbnail.jpg"} | 예약한 테마 |
