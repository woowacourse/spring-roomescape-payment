## 예약하기

> **POST /reservations**

### Request

- **헤더**

  |   이름   |       예시 값       |        설명         |
  |:------:|:----------------:|:-----------------:|
  | Cookie | token={JwtToken} | 로그인을 통해 얻은 JWT 토큰 |

- **본문**
    
  |   필드    |    예시 값    |       설명       |
  |:-------:|:----------:|:--------------:|
  |  date   | 2001-01-01 |    예약하려는 날짜    |
  | timeId  |     1      | 예약하려는 시간 슬롯 ID |
  | themeId |     1      |  예약하려는 테마 ID   |


### Response

> **201 CREATED**

- **본문**
    
    |  필드   |                                    예시 값                                    |   설명   |
    |:-----:|:--------------------------------------------------------------------------:|:------:|
    |  id   |                                     1                                      | 예약 ID  |
    | user  |                            {id: 1, name: "어드민"}                            |  예약자   |
    | date  |                                 2001-01-01                                 | 예약한 날짜 |
    | time  |                        {id: 1, startAt: "10:00:00"}                        | 예약한 시간 |
    | theme | {id: 1, name: "라라랜드", description: "라라랜드입니다.", thumbnail: "thumbnail.jpg"} | 예약한 테마 |

## 예약 조회

> **GET /reservations**

### Request

- **쿼리 파라미터**

  |    이름    |    예시 값    |   설명   | 필수 |
  |:--------:|:----------:|:------:|:--:|
  | themeId  |     1      | 테마 ID  | X  |
  |  userId  |     1      | 사용자 ID | X  |
  | dateFrom | 2001-01-01 | 시작 날짜  | X  |
  |  dateTo  | 2001-01-10 | 마지막 날짜 | X  |

> **200 OK**

  | user  |                            {id: 1, name: "어드민"}                            |  예약자   |

## 예약 취소

> **POST /reservations/cancel/{id}**

### Request

- **헤더**

  |   이름   |       예시 값       |        설명         |
  |:------:|:----------------:|:-----------------:|
  | Cookie | token={JwtToken} | 로그인을 통해 얻은 JWT 토큰 |

- **경로 변수 (URL Path)**

  | 필드 | 예시 값 |     설명      |
  |:--:|:----:|:-----------:|
  | id |  1   | 취소하려는 예약 ID |

### Response

> **204 NO CONTENT**
