# 사용자

사용자(User) REST API 엔드포인트에 대한 문서입니다.

로그인 및 회원가입, 사용자 기능을 포함합니다.

실패 응답에 대해서는 [여기](exception.md)를 참고해주세요.

## 회원가입 하기

> **POST /users**

### Request

- **본문**

  |    필드    |  자료형   |       예시 값       |            설명            |
  |:--------:|:------:|:----------------:|:------------------------:|
  |  email   | String | "popo@email.com" | 이메일 주소 (이메일 형식, 50자 이하)  |
  | password | String |  "awvn2uv4par!"  | 비밀번호 (공백 포함 불가, 30자 이하)  |
  |   name   | String |       "포포"       | 사용자 이름 (공백 포함 불가, 5자 이하) |

### Response

> **201 CREATED**

- **본문**

  |  필드  |  자료형   | 예시 값 |            설명            |
  |:----:|:------:|:----:|:------------------------:|
  |  id  | Number |  1   |          사용자 ID          |
  | name | String | "포포" | 사용자 이름 (공백 포함 불가, 5자 이하) |

## 로그인 하기

> **POST /login**

### Request

- **본문**

  |    필드    |  자료형   |       예시 값       |            설명            |
  |:--------:|:------:|:----------------:|:------------------------:|
  |  email   | String | "popo@email.com" | 이메일 주소 (이메일 형식, 50자 이하)  |
  | password | String |  "awvn2uv4par!"  | 비밀번호 (공백 포함 불가, 30자 이하)  |

### Response

> **200 OK**

- **헤더**

  |     이름     |  자료형   |       예시 값       |         설명         |
  |:----------:|:------:|:----------------:|:------------------:|
  | Set-Cookie | String | token={JwtToken} | 로그인을 통해 발급된 JWT 토큰 |

## 현재 로그인한 사용자 조회하기

> **GET /login/check**

### Request

- **헤더**

  |   이름   |  자료형   |       예시 값       |            설명             |
  |:------:|:------:|:----------------:|:-------------------------:|
  | Cookie | String | token={JwtToken} | **관리자** 로그인을 통해 얻은 JWT 토큰 |

### Response

> **200 OK**

- **본문**

  |  필드  |  자료형   | 예시 값 |            설명            |
  |:----:|:------:|:----:|:------------------------:|
  |  id  | Number |  1   |          사용자 ID          |
  | name | String | "포포" | 사용자 이름 (공백 포함 불가, 5자 이하) |

---

## 내 예약 조회하기

> **GET /users/reservations**

### Request

- **헤더**

  |   이름   |  자료형   |       예시 값       |            설명             |
  |:------:|:------:|:----------------:|:-------------------------:|
  | Cookie | String | token={JwtToken} | **관리자** 로그인을 통해 얻은 JWT 토큰 |

### Response

> **200 OK**

- **본문**

  아래와 같은 예약들로 이루어진 컬렉션을 응답합니다.

  |         필드          |   자료형    |                                    예시 값                                    |   설명   |
  |:-------------------:|:--------:|:--------------------------------------------------------------------------:|:------:|
  |         id          |  Number  |                                     1                                      | 예약 ID  |
  |  [user](./user.md)  | JSON Map |                            {id: 1, name: "포포"}                             |  예약자   |
  |        date         |   Date   |                                 2001-01-01                                 | 예약한 날짜 |
  |  [time](./time.md)  | JSON Map |                        {id: 1, startAt: "10:00:00"}                        | 예약한 시간 |
  | [theme](./theme.md) | JSON Map | {id: 1, name: "라라랜드", description: "라라랜드입니다.", thumbnail: "thumbnail.jpg"} | 예약한 테마 |
