# 사용자

사용자(User) REST API 엔드포인트에 대한 문서입니다.

로그인 및 회원가입, 사용자 기능을 포함합니다.

실패 응답에 대해서는 [여기](exception.md)를 참고해주세요.

- [로그인 하기](#로그인-하기)

- [내 예약 조회하기](#내-예약-조회하기)

## 회원가입 하기

> **POST /users**

### Request

- **본문**

  |    필드    |       예시 값       |   설명   |
  |:--------:|:----------------:|:------:|
  |  email   | "popo@email.com" | 이메일 주소 |
  | password |  "awvn2uv4par!"  |  비밀번호  |
  |   name   |       "포포"       | 사용자 이름 |

### Response

> **201 CREATED**

- **본문**

  |  필드  | 예시 값 |   설명   |
  |:----:|:----:|:------:|
  |  id  |  1   | 사용자 ID |
  | name | "포포" | 사용자 이름 |

---

## 로그인 하기

> **POST /login**

### Request

- **본문**

  |    필드    |       예시 값       |   설명   |
  |:--------:|:----------------:|:------:|
  |  email   | "popo@email.com" | 이메일 주소 |
  | password |  "awvn2uv4par!"  |  비밀번호  |

### Response

> **200 OK**

- **헤더**

  |     이름     |       예시 값       |         설명         |
  |:----------:|:----------------:|:------------------:|
  | Set-Cookie | token={JwtToken} | 로그인을 통해 발급된 JWT 토큰 |

---

## 현재 로그인한 사용자 조회하기

> **GET /login/check**

### Request

- **헤더**

  |   이름   |       예시 값       |        설명         |
  |:------:|:----------------:|:-----------------:|
  | Cookie | token={JwtToken} | 로그인을 통해 얻은 JWT 토큰 |

### Response

> **200 OK**

- **본문**

  |  필드  | 예시 값 |   설명   |
  |:----:|:----:|:------:|
  |  id  |  1   | 사용자 ID |
  | name | "포포" | 사용자 이름 |

---

## 내 예약 조회하기

> **GET /users/reservations**

### Request

- **헤더**

  |   이름   |       예시 값       |        설명         |
  |:------:|:----------------:|:-----------------:|
  | Cookie | token={JwtToken} | 로그인을 통해 얻은 JWT 토큰 |

### Response

> **200 OK**

- **본문**

  아래와 같은 예약들로 이루어진 컬렉션을 응답합니다.

  |  필드   |                                    예시 값                                    |   설명   |
  |:-----:|:--------------------------------------------------------------------------:|:------:|
  |  id   |                                     1                                      | 예약 ID  |
  | user  |                            {id: 1, name: "어드민"}                            |  예약자   |
  | date  |                                 2001-01-01                                 | 예약 날짜  |
  | time  |                        {id: 1, startAt: "10:00:00"}                        | 예약 시간  |
  | theme | {id: 1, name: "라라랜드", description: "라라랜드입니다.", thumbnail: "thumbnail.jpg"} | 예약 테마  |
