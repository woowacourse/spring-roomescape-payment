# 예외

REST API의 공통된 예외 응답에 대한 문서입니다.

[RFC 7807 - Problem Details for HTTP APIs](https://datatracker.ietf.org/doc/html/rfc7807) 명세에 따라 응답합니다.

## 공통된 예외 응답

### Response

- **본문**

  |    필드    |         예시 값          |                설명                |
  |:--------:|:---------------------:|:--------------------------------:|
  |   type   |      about:blank      | 문제 유형에 대한 URI (대부분 정의되어있지 않습니다.) |
  |  title   |     Unauthorized      |           문제 유형에 대한 요약           |
  |  status  |          401          |            HTTP 상태 코드            |
  |  detail  |      인증에 실패했습니다.      |          문제에 대한 구체적인 설명          |
  | instance |        /login         |           문제가 발생한 URI            |
  | message  | "이메일 또는 비밀번호가 틀렸습니다." |               메시지                |

## HTTP 상태 코드 별 예외 상황

> **400 BAD REQUEST**

- 잘못된 요청을 보냈을 때 발생합니다.
- 유효성 검사에 실패했을 때 주로 발생합니다.

> **401 UNAUTHORIZED**

- 인증에 실패했을 때 발생합니다.
  - ex) 로그인하지 않은 채 예약 페이지에 접근할 때

> **403 FORBIDDEN**

- 인가에 실패했을 때 발생합니다.
  - ex) 일반 유저가 관리자 페이지에 접근할 때

> **404 NOT FOUND**

- 요청한 대상을 찾을 수 없을 때 발생합니다.
  - ex) 존재하지 않는 테마에 예약하려 할 때

> **409 CONFLICT**

- 요청한 대상이 중복되었을 때 발생합니다.
  - ex) 같은 날짜, 시간, 테마에 대한 예약을 또 수행할 때
- 요청한 대상이 다른 자원과의 충돌로 인해 요청이 수행될 수 없을 때 발생합니다.
  - ex) 테마를 삭제할 때, 해당 테마에 대한 예약이 있을 때

> **422 UNPROCESSABLE ENTITY**

- 요청이 비즈니스 규칙을 위반했을 때 발생합니다.
  - ex) 과거 일시로 예약하려 할 때

> **500 INTERNAL SERVER ERROR**

- 방탈출 서버에 예기치 못한 오류가 생겼을 때 발생합니다.
  - ex) 방탈출 서버의 문제로 결제에 실패했을 때
- 외부 서버의 예기치 못한 오류가 생겼을 때 발생합니다.
  - ex) PG사 서버의 문제로 결제에 실패했을 때
