# 예약 시간

예약 시간 REST API 엔드포인트에 대한 문서입니다.

예약 시간은 방탈출 시작 시간을 의미합니다.

실패 응답에 대해서는 [여기](exception.md)를 참고해주세요.

## 시간 등록하기

> **POST /times**

> **⚠️ 관리자만 수행할 수 있습니다.**

### Request

- **헤더**

  |   이름   |       예시 값       |            설명             |
  |:------:|:----------------:|:-------------------------:|
  | Cookie | token={JwtToken} | **관리자** 로그인을 통해 얻은 JWT 토큰 |

- **본문**
    
  |   필드    |  예시 값   |      설명       |
  |:-------:|:-------:|:-------------:|
  | startAt | "13:00" | 등록할 방탈출 시작 시간 |


### Response

> **201 CREATED**

- **본문**
    
    |   필드    |    예시 값    |          설명          |
    |:-------:|:----------:|:--------------------:|
    |   id    |     1      |        시간 ID         |
    | startAt | "10:00:00" | 방탈출 시작 시간 (HH:mm:ss) |

## 모든 시간 조회하기

> **GET /times**

### Request

  (없음)

### Response

> **200 OK**

- **본문**

    아래와 같은 예약 시간들로 이루어진 컬렉션을 응답합니다.

  |   필드    |    예시 값    |          설명          |
  |:-------:|:----------:|:--------------------:|
  |   id    |     1      |        시간 ID         |
  | startAt | "10:00:00" | 방탈출 시작 시간 (HH:mm:ss) |

---

## 특정 날짜와 테마에 대해 예약 가능한 시간 조회하기

> **GET /times/available**

### Request

- **쿼리 파라미터**

  |   이름    |    예시 값    |          설명          | 필수 |
  |:-------:|:----------:|:--------------------:|:--:|
  |  date   | 2001-01-10 |  예약 가능한 시간을 조회할 날짜   | O  |
  | themeId |     1      | 예약 가능한 시간을 조회할 테마 ID | O  |

### Response

> **200 OK**

- **본문**

    아래와 같은 예약들로 이루어진 컬렉션을 응답합니다.

  |      필드       |    예시 값    |          설명          |
  |:-------------:|:----------:|:--------------------:|
  |      id       |     1      |        시간 ID         |
  |    startAt    | "10:00:00" | 방탈출 시작 시간 (HH:mm:ss) |
  | alreadyBooked |    true    |    이미 예약되었는 지 여부     |

## 시간 삭제

> **DELETE /times/{id}**

> **⚠️ 관리자만 수행할 수 있습니다.**

### Request

- **헤더**

  |   이름   |       예시 값       |            설명             |
  |:------:|:----------------:|:-------------------------:|
  | Cookie | token={JwtToken} | **관리자** 로그인을 통해 얻은 JWT 토큰 |

- **경로 변수 (URL Path)**

  | 필드 | 예시 값 |     설명      |
  |:--:|:----:|:-----------:|
  | id |  1   | 삭제하려는 시간 ID |

### Response

> **204 NO CONTENT**
