## 테마 등록하기

> **POST /themes**

> **⚠️ 관리자만 수행할 수 있습니다.**

### Request

- **헤더**

  |   이름   |       예시 값       |            설명             |
  |:------:|:----------------:|:-------------------------:|
  | Cookie | token={JwtToken} | **관리자** 로그인을 통해 얻은 JWT 토큰 |

- **본문**
    
  |     필드      |                 예시 값                  |      설명      |
  |:-----------:|:-------------------------------------:|:------------:|
  |    name     |               "공포의 대저택"               |    테마 이름     |
  | description |             "공포의 대저택입니다."             |    테마 설명     |
  |  thumbnail  | "https://.../images/horror_house.jpg" | 썸네일 이미지 URL  |


### Response

> **201 CREATED**

- **본문**

  |     필드      |                 예시 값                  |     설명      |
  |:-----------:|:-------------------------------------:|:-----------:|
  |     id      |                   1                   |    테마 ID    |
  |    name     |               "공포의 대저택"               |    테마 이름    |
  | description |             "공포의 대저택입니다."             |    테마 설명    |
  |  thumbnail  | "https://.../images/horror_house.jpg" | 썸네일 이미지 URL |

## 인기 테마 조회하기

테마 별 예약된 횟수를 기준으로 인기 테마를 조회합니다.

> **GET /themes/popular**

### Request

- **쿼리 파라미터**

  |    이름     |    예시 값    |         설명         | 필수 |
  |:---------:|:----------:|:------------------:|:--:|
  | startDate | 2001-01-01 | 집계할 예약들에 대한 시작 날짜  | O  |
  |  endDate  | 2001-01-10 | 집계할 예약들에 대한 마지막 날짜 | O  |
  |   count   |     5      |  조회할 인기 테마의 최대 개수  | O  |

### Response

> **200 OK**

- **본문**

    아래와 같은 예약들로 이루어진 컬렉션을 응답합니다.

  |     필드      |                 예시 값                  |     설명      |
  |:-----------:|:-------------------------------------:|:-----------:|
  |     id      |                   1                   |    테마 ID    |
  |    name     |               "공포의 대저택"               |    테마 이름    |
  | description |             "공포의 대저택입니다."             |    테마 설명    |

## 테마 삭제하기

> **DELETE /themes/{id}**

> **⚠️ 관리자만 수행할 수 있습니다.**

### Request

- **헤더**

  |   이름   |       예시 값       |            설명             |
  |:------:|:----------------:|:-------------------------:|
  | Cookie | token={JwtToken} | **관리자** 로그인을 통해 얻은 JWT 토큰 |

- **경로 변수 (URL Path)**

  | 필드 | 예시 값 |     설명      |
  |:--:|:----:|:-----------:|
  | id |  1   | 삭제하려는 테마 ID |

### Response

> **204 NO CONTENT**
