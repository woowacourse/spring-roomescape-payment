== 데이터 모델

=== ReservationResponse

|===
|필드명|타입|설명

|id
|Long
|예약 ID

|date
|String
|예약 날짜 (YYYY-MM-DD 형식)

|time
|ReservationTimeResponse
|예약 시간 정보

|theme
|ThemeResponse
|테마 정보

|member
|MemberResponse
|회원 정보
|===
