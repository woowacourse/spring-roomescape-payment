== 예약 대기 API

=== 대기 생성

예약 대기를 생성할 수 있다. 예약 대기는 예약이 마감된 후에 대기할 수 있는 기능이다.
예약 대기를 생성하면, 예약이 취소되었을 때 순번에 따라 자동으로 예약이 된다.
