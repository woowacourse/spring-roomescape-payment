[[overview]]
= 개요

이 문서는 Room Escape 예약 API에 대한 문서입니다.
이 API는 사용자가 방탈출 예약을 생성하고 관리할 수 있도록 합니다.
또한 관리자는 모든 예약을 조회하고 삭제할 수 있습니다.
