# 방 탈출 예약

## 기능 구현 사항

- [ ] 사용자가 날짜, 테마, 시간을 선택하고 결제를 해야 예약할 수 있도록 변경합니다.
    - [ ] 결제를 해야 예약이 되게 변경
    - [ ] 결제를 해야 예약 대기가 되게 변경 (다음 단계)
  
- [ ] 결제 기능은 외부의 결제 서비스를 사용하여 외부의 결제 API를 연동하세요.
    - [ ] tosspay 사용

- [ ] 결제 승인 API 호출에 실패 한 경우, 안전하게 에러를 핸들링 하세요.
    - [ ] 사용자는 예약 실패 시, 결제 실패 사유를 알 수 있어야 합니다.
