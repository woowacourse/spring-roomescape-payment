# 방탈출 결제 / 배포

### 접근 방법 
- 관리자 계정:
    ```plaintext
      email: asd@naver.com
      password: 1234
    ```
- 사용자 계정:
    ```plaintext
  email: user1@example.com
  password: pass1
   ```

### 기능 요구 사항 
- [x] 방탈출 예약시 결제 UI를 제공한다.  
- [x] 방탈출 예약시 toss를 이용해 결제가 가능하도록 API를 구현한다. 
  - [x] 결제가 실패한 경우 결제 실패에 대한 내용을 사용자에게 제공한다.
