# 방탈출 결제 / 배포

## 1단계 기능 구현
- [x] 사용자가 날짜, 테마, 시간을 선택하고 결제를 해야 예약할 수 있도록 변경
- [x] 외부의 결제 API를 연동하여 결제 기능 구현
- [x] 결제 승인 API 호출에 실패 한 경우, 에러 핸들링 처리
  - [x] 예약 실패 시, 결제 실패 사유를 사용자에게 알림

## 2단계 기능 구현
- [x] 사용자의 예약 페이지에서 결제 정보를 확인할 수 있도록 변경
- [x] 결제 정보를 데이터베이스에 저장하는 기능 구현

## 3단계 기능 구현
- [x] AWS 클라우드 서버에 방탈출 예약 서비스를 배포
- [x] 구현 코드를 서버에 배포하는 shell 스크립트 작성

## 4단계 기능 구현
- [x] 사용자 예약 페이지에서 호출하는 API에 대한 문서 작성
- [x] 방탈출 예약 서비스의 데이터베이스 구조에 대한 ERD 작성
