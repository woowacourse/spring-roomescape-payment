# 방탈출 결제/배포

## 1단계 - 예약 시 결제단계 추가

사용자가 날짜, 테마, 시간을 선택하고 결제를 해야 예약을 할 수 있습니다.

- 결제 기능은 외부의 결제 서비스를 사용하여 외부의 결제 API를 연동합니다.
- 결제 승인 API 호출에 실패 한 경우, 에러를 핸들링 합니다.
    - 예약 실패 시 사용자에게 결제 실패 사유를 표시해야 합니다.

## 2단계 - 내 예약 페이지 표시 정보 변경

- 내 예약 페이지에서 예약 정보와 결제 정보를 표시합니다.
    - 테마명
    - 날짜
    - 시간
    - 예약 상태
    - paymentKey
    - 결제금액

## 3단계 - 배포하기

- 리눅스 서버에 작성한 spring boot 웹 서버를 배포합니다.
- [배포 서버 주소](http://eoehd1ek.com:8080/)
- 사용한 배포 스크립트는 `deploy.sh` 파일입니다.
    - 배포 스크립트가 동작하기 위해서는 jdk 21 설치가 되어 있어야 합니다.
- 배포 서버 운영체제는 로컬 Ubuntu 24.04 LTS 입니다.

## 4단계 - 문서화, 로깅

- `사용자 예약 페이지`에서 호출하는 모든 API를 확인 할 수 있는 API 문서를 작성합니다.
- Database ERD 를 작성하고, 작성 시 테이블 간의 관계를 표현합니다.
- API 문서, ERD를 PR내용에 포함하여 리뷰 요청하세요.
- 적절한 log 라이브러리를 선택하여 로그를 기록합니다.
    - 서비스 운영 시 모니터링 및 에러 트래킹을 위해 로그 레벨(e.g. DEBUG, INFO, WARN, ERROR 등)을 구분하여 로그를 기록합니다.
