- [x] 예약 대기를 추가할 수 있다.
- [x] 예약 대기를 삭제할 수 있다.

### 결제

- [x] 예약대기시에도 결제를 해야한다

- [x] 결제에 문제가 생기면 예약이 되지 않는다
