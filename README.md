# 방탈출 결제/배포

## 1단계 - 예약 시 결제단계 추가

사용자가 날짜, 테마, 시간을 선택하고 결제를 해야 예약을 할 수 있습니다.

- 결제 기능은 외부의 결제 서비스를 사용하여 외부의 결제 API를 연동합니다.
- 결제 승인 API 호출에 실패 한 경우, 에러를 핸들링 합니다.
    - 예약 실패 시 사용자에게 결제 실패 사유를 표시해야 합니다.

## 2단계 - 내 예약 페이지 표시 정보 변경

- 내 예약 페이지에서 예약 정보와 결제 정보를 표시합니다.
    - 테마명
    - 날짜
    - 시간
    - 예약 상태
    - paymentKey
    - 결제금액
